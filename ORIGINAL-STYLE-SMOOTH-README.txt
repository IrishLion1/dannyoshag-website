ORIGINAL-STYLE SMOOTH BUILD

This build preserves the original psychedelic visual design:
- The original animated photo treatments remain different for every photograph.
- The original animated desktop and mobile backgrounds remain in use.
- No generic CSS color overlay replaces the animations on mobile.

Performance changes only:
- Smaller H.264 encodes derived from the original MP4 animations.
- A real photograph sits underneath every video while it loads.
- Mobile plays only the foreground video nearest the center of the screen.
- The next foreground video is preloaded but not played.
- Delayed scroll restoration no longer fights touch scrolling.
- Autoplay is retried after touch/click and after returning to Instagram.
